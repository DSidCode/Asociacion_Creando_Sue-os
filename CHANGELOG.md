# CHANGELOG - Asociación Creando Sueños Web

Todos los cambios notables en este proyecto serán documentados en este archivo.

## [1.0.0] - 2026-08-23

### 🌟 Añadido
- **Maquetación Completa de `index.html`:** Estructura web modular optimizada para la junta directiva y la comunidad migrante en España.
- **Sistema de Colores ONG Internacional (ACNUR / Cruz Roja / UNICEF):**
  - Azul Marino Institucional (`#002B66`) para legalidad y confianza.
  - Dorado Sol (`#FFC72C`) para identidad cultural y calidez.
  - Verde Esmeralda (`#00A859`) para atención en directo.
  - Rojo Carmesí (`#DA291C`) para donaciones.
- **Hero Section Monumental:** Titular de alto impacto *"Migrar no tiene que significar estar solo"*, métricas sociales (+1.200 atendidos) y tarjeta institucional de Edilma Saraza.
- **Sección Extranjería & Trámites:** Tarjetas interactivas para Arraigos, NIE, Parejas de Hecho y Homologaciones (SENA).
- **Módulo Deportivo "La Banda" ⚽:** Ficha técnica del equipo de fútbol con el uniforme oficial Cóndor Real y botón de inscripción.
- **Widget Flotante de WhatsApp Repotenciado:** Cápsula interactiva con indicador en vivo de atención personalizada, ajustada para evitar superposición con barras de desplazamiento.
- **Documentación de Estudio & Propuesta Comercial:**
  - `guia_estudio_propuesta_web_creando_suenos.md` (Para estudio en NotebookLM).
  - `reporte_propuesta_web.html` (Dashboard de presentación comercial).
  - `README.md` (Documentación oficial del repositorio).
